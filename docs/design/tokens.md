# 디자인 토큰

ztgate 의 모든 화면(웹 콘솔, Windows GUI, 터미널 출력, README 그림)이 같은 색을 쓴다. 보안 제품이라
차분하고 믿음직하게: 바탕은 딥 네이비와 밝은 회청, 강조는 네이비 블루, 포인트는 청록 하나.
빨강과 노랑은 상태(차단, 경고)에만 쓴다.

## 상태

어디서나 같은 뜻, 같은 색이다.

| 상태 | 색 | 예 |
|---|---|---|
| 연결됨 · 허용 · 실행 중 | `teal` | 세션, `allow`, 서버 실행 중 |
| 경고 | `warn` | 포스처 조건 일부 미달, 곧 만료 |
| 차단 · 거절 · 멈춤 | `danger` | `deny`, `auth_denied`, 서버 멈춤 |
| 대기 · 끊김 | `idle` | 등록 대기, 연결 끊김 |
| 정보 | `accent` | 핸드셰이크, 다시 읽기 |

## 터미널

터미널은 기본 16색만 쓴다 (어떤 테마에서도 읽히게). 표준 출력이 터미널이고 `NO_COLOR` 가 없을 때만 색을 넣는다.

| 상태 | ANSI |
|---|---|
| 연결됨 · 허용 · 성공 | 청록 `36` |
| 경고 | 노랑 `33` |
| 차단 · 실패 | 빨강 `31` |
| 보조 글 | 흐리게 `2` |
| 제목 | 굵게 `1` |

## 글꼴과 간격

- 글꼴: `system-ui, "Segoe UI", "Malgun Gothic", "Apple SD Gothic Neo", sans-serif`. 고정폭: `ui-monospace, Consolas, "D2Coding", monospace`. 외부 글꼴은 받지 않는다.
- 크기: 본문 14px, 보조 12px, 제목 20 / 16px, 숫자 카드 26px.
- 간격: 4 · 8 · 12 · 16 · 24 · 32 px.
- 모서리: 작은 것 6px, 카드 10px, 알약 배지 999px.
