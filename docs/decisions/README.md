# 설계 결정 기록 (ADR)

되돌리기 비싼 결정마다 그때의 맥락, 고른 것, 버린 다른 길, 그 결과로 떠안은 것을 한 장씩 남깁니다. 결정이 바뀌면 옛 기록을 지우지 않고, 새 기록을 쓰고 옛 기록의 상태를 "대체됨"으로 바꿉니다.

| # | 결정 | 상태 | 날짜 |
|---|---|---|---|
| [0001](0001-userspace-epoll-tun.md) | 서버는 유저 공간에서 epoll 과 tun 으로 돈다 | 채택 | 2026-09-20 |
| [0002](0002-own-handshake-fixed-suite.md) | 핸드셰이크는 직접 짜고, 암호 묶음은 협상하지 않고 고정한다 | 채택 | 2026-10-13 |
| [0003](0003-stateless-nonce-cookie.md) | nonce 는 서버가 기억하지 않는 쿠키로 한다 | 채택 | 2026-10-24 |
| [0004](0004-public-key-devices-server-key.md) | 등록하는 기기는 공개키만 올리고, 기기 키는 고정 키의 ECDH 로 뽑는다 | 채택 | 2026-10-24 |
| [0005](0005-workers-table-rwlock.md) | 워커 여럿은 세션 표 하나를 읽기 / 쓰기 잠금으로 나눠 쓴다 | 채택 | 2026-10-24 |
| [0006](0006-dual-stack-single-socket.md) | IPv4 와 IPv6 를 소켓 하나(듀얼스택)로 받는다 | 채택 | 2026-10-24 |
| [0007](0007-offline-jwt-dpop.md) | 사용자 토큰은 서버가 IdP 에 묻지 않고 확인하고, DPoP 로 기기에 묶는다 | 채택 | 2026-10-24 |
| [0008](0008-config-files-one-helper.md) | 설정은 텍스트 파일이고, 고치는 길은 ztgate_ctl 하나다 | 채택 | 2026-10-16 |
| [0009](0009-signed-update-manifest.md) | Windows 자동 업데이트는 서명한 매니페스트만 따른다 | 채택 | 2026-10-25 |
| [0010](0010-acl-later-fragments.md) | ACL 은 IP 뒷조각을 포트 없이 판정한다 | 채택 | 2026-10-25 |

날짜는 그 결정이 처음 코드에 들어간 커밋의 날짜입니다. 0001~0008 은 결정을 내린 뒤에 그때의 커밋과 문서를 보고 적은 것이라, "검토한 다른 길"은 그때 따로 적어 둔 비교가 아니라 지금 돌아보며 정리한 것입니다. 0009, 0010 은 결정과 함께 적었습니다.
