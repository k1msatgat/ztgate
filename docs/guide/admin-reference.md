# ztgate 운영 참고

서버를 운영할 때 찾아보는 사실을 모았습니다. 설치하고 기기를 등록하는 순서는 [ztgate 서버 운영하기](admin.md)에 있습니다.

## 서버 요건

| 항목 | 요건 |
|---|---|
| 운영체제 | Ubuntu 22.04, Ubuntu 24.04, Rocky Linux 9, RHEL 9 (x86_64) |
| 주소 | 공인 주소, 또는 공인 주소에서 서버로 오는 포트 포워딩 |
| 포트 | UDP 9000 (`PORT`). UDP 를 막는 네트워크의 PC 도 받으려면 같은 번호의 TCP 포트(`TCP_PORT=9000`)도 엽니다. Windows 클라이언트는 같은 번호의 TCP 포트로만 바꿔 연결합니다 |
| 이름 | 서버에 DNS 이름(`vpn.example.com`)을 붙이기를 권장합니다. PC 는 연결할 때마다 이름을 다시 조회하므로, 서버 주소가 바뀌어도 PC 를 다시 설정하지 않아도 됩니다 |
| 필요한 프로그램 | 관리 도구 `ztgate_ctl` 은 Node.js 18 이상이 필요합니다. Ubuntu 22.04 의 기본 `nodejs` 는 12 이므로 18 이상을 따로 설치합니다. nftables 는 서버 뒤의 사내망으로 내보낼 때, rsync 는 서버 두 대를 동기화할 때 필요합니다 |

## 매일 쓰는 명령

| 항목 | 명령 |
|---|---|
| 연결된 PC 와 그 상태 | `sudo ztgate status` |
| 감사 로그 | `sudo ztgate audit` (`/var/log/ztgate/audit.log`, 12주 보관) |
| 서버 로그 | `journalctl -u ztgate` |
| Prometheus 지표 | `sudo systemctl enable --now ztgate-exporter` 로 켠 뒤 `127.0.0.1:9469/metrics` |

웹 관리 콘솔의 **개요**와 **감사 로그** 화면도 같은 내용을 보여 줍니다.

## 문제 해결

| 증상 | 원인과 확인 사항 |
|---|---|
| PC 에 "서버가 답하지 않습니다"나 "다시 연결 중"이 계속 나온다 | 서버가 꺼져 있거나 UDP 포트가 막혔습니다. `systemctl status ztgate` 로 서버 상태를 확인하고, 서버의 방화벽과 클라우드 보안 그룹에서 UDP 포트가 열려 있는지 확인합니다. PC 가 UDP 를 막는 네트워크에 있으면 `TCP_PORT` 를 설정합니다 |
| PC 에 "서버에 이 기기가 없습니다"가 나온다 | 기기 목록에 그 기기가 없습니다. 지운 기기라면 새 코드로 다시 등록합니다 |
| PC 에 "이 PC 가 회사 보안 정책에 맞지 않습니다"가 나온다 | PC 의 포스처가 그 기기의 접속 조건에 못 미칩니다. 이 안내는 그 PC 에서 방화벽, 백신, BitLocker 가 꺼져 있지 않은데도 서버가 거부했을 때 나옵니다. 감사 로그의 `auth_denied` 줄에 사유가 있습니다 |
| 연결은 되는데 어떤 목적지에만 닿지 않는다 | 그 목적지를 허용하는 ACL 규칙이 없거나, 규칙의 태그, 사용자, 포스처 조건이 맞지 않습니다. 감사 로그의 `access` 줄에 판정이 있습니다 |
| PC 에 "서버가 이 프로그램보다 새 버전입니다"가 나온다 | PC 의 ztgate 가 서버보다 오래된 버전입니다. PC 의 ztgate 를 올립니다 |
| 초대 링크가 나오지 않는다 | `server.env` 에 `PUBLIC_ADDRESS` 가 없습니다 |
| 부 서버에서 설정을 고칠 수 없다 | 의도한 동작입니다. 설정은 주 서버에서 고치고, `ztgate-sync` 가 부 서버로 보냅니다 |

## 지금 할 수 없는 것

- 서버 키를 바꾸면 모든 기기가 다시 등록해야 합니다. 다시 등록하지 않고 서버 키를 바꾸는 방법은 설계하고 있습니다 ([ADR 0013](../decisions/0013-server-key-rotation.md)). 서버 키가 샜다고 의심되면 새 키를 만들고 모든 기기를 다시 등록합니다.
- 서버끼리 세션을 넘겨주지 않습니다. 다른 서버로 옮겨 간 PC 는 새로 연결하고, 옮겨 가는 몇 초 동안의 패킷을 잃습니다.
- macOS, iOS, Android 클라이언트가 없습니다.
